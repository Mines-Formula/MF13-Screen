# MF13 Screen

## Overview

This repository contains the steering wheel display and screen software used by Colorado School of Mines Formula SAE.

The codebase in this repository was used to develop and maintain the driver display systems from **MF8 through MF13**, representing multiple generations of Mines Formula SAE vehicles. Throughout these vehicles, the team utilized **Nextion embedded displays** as the primary driver interface, with this repository serving as the foundation for display logic, telemetry visualization, warning indicators, launch control feedback, and driver interaction features.

This repository is being archived as a historical snapshot of the MF13-era screen software and development practices.

## Hardware Platform

All vehicles supported by this repository utilized:

- Nextion embedded touchscreen displays
- Custom steering wheel electronics
- CAN bus communication with vehicle subsystems
- Microcontroller-based display controllers

## Repository Purpose

This software was responsible for presenting critical vehicle information to the driver, including:

- Vehicle status indicators
- Warning and fault notifications
- Sensor and telemetry data
- Launch control feedback
- Driver-selectable display pages
- Miscellaneous race-day diagnostics

## Historical Context

This repository represents the final evolution of the screen software architecture used from MF8 through MF13.

Over several competition seasons, numerous Formula SAE team members contributed features, bug fixes, hardware integrations, and user interface improvements. As a result, this repository serves as both an operational codebase and a historical record of the team's display system development.

## Archive Status

This repository has been archived and is preserved for:

- Historical reference
- Competition documentation
- Future team knowledge transfer
- Review of prior design decisions
- Reuse of concepts in future vehicle generations

The software contained here reflects the state of the codebase used during the MF13 competition season and is no longer under active development.
